## Priority Upgrade Pathway

1. **National Data Legibility Infrastructure (Intervention 01):** Mandate standardized, real-time PSNP transaction data routing to Credit Reference Bureau (CRB) Ethiopia under Fayda identifiers. Expected $\Delta$ARI: +0.5 to +0.7.
2. **Trust Architecture Enactment (Intervention 02):** Enact state-wide Personal Data Protection legislation with explicit beneficiary consent protocols and G2P transaction reversibility guarantees. Expected $\Delta$ARI: +0.3 to +0.5.
3. **Structured Finance Enablement (Intervention 03):** Establish a securitization/ABS pipeline using MFI micro-loan portfolios on the Ethiopian Securities Exchange (ESX). Expected $\Delta$ARI: +0.3 to +0.5.
4. **Agent Commission Restructuring (Intervention 04):** Revamp rural agent fee schemes to a distance-adjusted scale and deploy automated rural cash depots (e.g., via EthioPost branches) to resolve cash-out liquidity constraints. Expected $\Delta$ARI: +0.2 to +0.4.
5. **Regulatory Sandbox Operationalization (Intervention 05):** Activate the 2025 fintech regulatory sandbox and simplify KYC onboarding for G2P disbursement points, particularly to reduce entry barriers for female-led micro enterprises. Expected $\Delta$ARI: +0.2 to +0.3.
