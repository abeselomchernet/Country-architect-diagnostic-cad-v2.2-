# Country Architect Diagnostic (CAD) v2.2 — Strategic Roadmap

This document outlines the planned trajectory for the **Country Architect Diagnostic (CAD)** framework and interactive simulation engine. 

---

## Phase I: Platform Consolidation & Core Asset Release (Q3 2026) 
- [x] **Universal Dynamic Engine**: Implement full interactive calculations for the Architect Readiness Index (ARI), Lock Intensity Coefficient (LIC), and dynamic Momentum score.
- [x] **Worked Country Benchmark**: Release the full worked assessment of Ethiopia's Digital G2P Social Payments System (PSNP).
- [x] **Offline Portability**: Maintain a standalone, offline-ready HTML calculator (`calculator/cad-calculator.html`) with zero dependencies to function in regions with limited connectivity.
- [x] **Academic Standards Alignment**: Release standard citation formats (`CITATION.cff`) and JEL JEL: O10, O16, O17 classifications.
- [ ] **Vector Graphic Assets**: Add fully responsive SVG schema diagrams to visually represent the CAD Architecture, System Lifecycle, and Operating Models within the documentation browser.

## Phase II: Assessment Expansion & Multi-Country Comparison (Q4 2026 - Q1 2027)
- [ ] **Community-Sourced Assessments**: Open sub-directories for peer-reviewed country assessments (e.g., Nigeria, Kenya, Colombia, Bangladesh).
- [ ] **Multi-Country Dashboard**: Build a side-by-side comparison dashboard inside the React interactive platform, allowing users to contrast ARI matrices between comparable emerging economies.
- [ ] **JSON Export / Import Schema**: Define a structured JSON schema for CAD assessments, enabling users to download, upload, and share calculated profiles directly between portals.
- [ ] **Print & PDF Layouts**: Build specialized print style sheets for the web assessment output, enabling researchers to click "Print" and produce professional, beautifully typeset paper reports.

## Phase III: Advanced Analytics & AI-Assisted Diagnostics (Q2 2027 - Q3 2027)
- [ ] **Lightweight SDK (`@cad-framework/engine`)**: Package the mathematical calculation formulas and taxonomy logic into a headless NPM package, permitting development portals to run CAD analytics natively.
- [ ] **LLM Grounding Interface**: Standardize system prompts and integration layers for Large Language Models (like Gemini) to read structural ecosystem briefs and pre-populate draft CAD assessments.
- [ ] **Live Data Feed Grounding**: Implement API bridges to fetch real-world proxy indices dynamically (such as GSMA Mobile Money prevalence, World Bank ID4D databases, and ITU cybersecurity ratings) and recommend preliminary pillar baselines.
